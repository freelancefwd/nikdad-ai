# nikdad.ai

Statische persönliche Website. Kein Build-Schritt nötig.

- `index.html` – Startseite
- `impressum.html`, `datenschutz.html` – Rechtstexte (Platzhalter in eckigen Klammern ausfüllen)
- `fonts/` – selbst gehostete Schriften (DSGVO-konform, kein Google-Fonts-Abruf)
- `render.yaml` – Render Blueprint (Static Site)

Deploy: Repo auf GitHub anlegen, in Render „New → Blueprint“ wählen, Repo verbinden.
